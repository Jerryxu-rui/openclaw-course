# OpenClaw课程宣传PPT/HTML演示文稿

## 📋 概述
本文件夹包含OpenClaw课程的宣传PPT/HTML演示文稿，用于课程推广和展示。

## 🎯 目标
创建一套完整的、可交互的课程宣传演示文稿，包含：
1. 课程介绍和亮点
2. 详细课程大纲
3. 金融实战案例展示
4. 定价策略和报名信息
5. 响应式设计，支持多设备

## 📁 文件结构
```
promo-presentation/
├── README.md                    # 本文件
├── openclaw-course-promo-presentation.html  # 基础版演示文稿
├── openclaw-course-promo-advanced.html      # 高级版演示文稿
├── test.html                    # 测试页面（快速访问入口）
├── assets/                      # 资源文件夹（图片、字体等）
│   ├── images/                  # 图片资源
│   ├── fonts/                   # 字体文件
│   └── css/                     # 样式文件
└── scripts/                     # JavaScript脚本
```

## 🎨 设计规范
- **主色调**：蓝紫色渐变 (#050508 → #0a0a1a → #0d1528)
- **辅助色**：金色点缀 (#FFD700)
- **字体**：Noto Sans SC（中文字体）
- **风格**：现代科技风，简洁专业

## 📱 功能特性
1. **响应式设计**：支持手机、平板、电脑
2. **可翻页演示**：左右箭头导航，键盘支持
3. **动画效果**：平滑过渡，粒子背景
4. **进度指示**：显示当前页/总页数
5. **打印支持**：可导出为PDF

## 🚀 使用方法

### 快速开始
1. 打开 `test.html` 查看所有演示文稿的概览和链接
2. 或直接打开对应的演示文稿文件：
   - `openclaw-course-promo-presentation.html` - 基础版
   - `openclaw-course-promo-advanced.html` - 高级版

### 导航控制
- **键盘**：左右箭头键翻页，PageUp/PageDown，Home/End跳转
- **鼠标**：点击导航按钮，使用滚轮翻页
- **触摸**：在手机/平板上水平滑动
- **快捷键**：F键全屏，ESC退出全屏，Ctrl+P打印

### 浏览器兼容性
- Chrome 90+ ✓
- Firefox 88+ ✓
- Safari 14+ ✓
- Edge 90+ ✓
